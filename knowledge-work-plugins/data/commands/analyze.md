---
name: analyze
description: Answer data questions by querying connected data sources
---

Answer the data question by:
1. Identifying which data sources contain the relevant data
2. Writing optimized SQL or API queries to retrieve it
3. Analyzing the results and identifying key patterns
4. Presenting findings with clear visualizations when helpful
5. Noting any caveats, data quality issues, or limitations

Always cite the source table/dataset for each data point.
