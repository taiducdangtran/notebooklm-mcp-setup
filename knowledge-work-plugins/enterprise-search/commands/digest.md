---
name: digest
description: Generate daily or weekly activity summaries across all sources
---

Generate a digest of recent activity:
1. Scan all connected sources for the specified time period
2. Group updates by project, team, or topic
3. Highlight decisions made, action items created, and key discussions
4. Surface anything that may need your attention or follow-up
5. Format as a scannable summary with links to originals

Default: daily digest. Add `--weekly` for a 7-day rollup.
