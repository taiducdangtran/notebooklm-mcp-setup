name: performance-report
description: Pull marketing metrics, identify trends, and generate recommendations
---

Generate a marketing performance report:
1. Pull metrics from Amplitude, HubSpot, and other connected tools
2. Compare against previous period and targets
3. Identify top-performing and underperforming content/campaigns
4. Surface key trends and anomalies
5. Provide 3-5 actionable recommendations

Default time range: last 30 days. Override with: --range 7d | 30d | 90d | ytd
